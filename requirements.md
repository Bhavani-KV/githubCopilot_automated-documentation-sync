# Requirements

- Build a simple standalone web page for package delivery tracking.
- Allow the user to enter a tracking number.
- Include a Track button that cahecks the tracking number when clicked.
- Use sample/mock data for delivery statuses.
- Support these statuses: Order Received, In Transit, Out for Delivery, and Delivered.
- Support these sample tracking numbers:
	- `TRK-1001` - Order Received
	- `TRK-1002` - In Transit
	- `TRK-1003` - Out for Delivery
	- `TRK-1004` - Delivered
- Show an error message when the tracking number is not found in the sample data.
- Display both the tracking number and its current delivery status.
